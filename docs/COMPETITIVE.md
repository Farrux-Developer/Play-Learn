# Competitive Scan (`docs/COMPETITIVE.md`)

> **Verification Disclosure:** No live external browsing was performed for this scan. Observations below are synthesized from domain knowledge of CS education products and are **unverified against live 2026 product updates**.

| Product | Age / Target | What It Does Best | Key Gap / Where «Oʻyna va oʻrgan» Wins |
|---|---|---|---|
| **Code.org (CS Fundamentals)** | K–5 / K–12 | Structured courses, Blockly puzzles, huge teacher curriculum alignment | English-first, thin Uzbek support, relies on server accounts and videos, less focus on CPU/memory notional machine |
| **Scratch** | 8–16 | Open creative sandbox, instant visual expression, remix community | Freeform sandbox can overwhelm beginners without mastery-gated repair/debug levels or CS fundamentals (binary, networks, CPU) |
| **Lightbot** | 8–12 | Pure intrinsic integration of sequencing, procedures & recursion with tight spatial puzzles | Stops at robot movement; no variables, memory cells, binary, logic gates, networks, or conceptual explanation pages |
| **Human Resource Machine** | 12+ | Brilliant tactile assembly notional machine (inbox, outbox, floor memory tiles, registers) | Steep difficulty spike, zero Uzbek/child scaffolding, no worked examples or misconception-specific hints |
| **The Nand Game** | 14+ / CS | Bottom-up progression from NAND → gates → ALU → RAM → CPU | Too abstract/text-heavy for 10–12 y.o.; no story/coach, no algorithms/networks/safety modules |
| **Turing Complete** | 14+ / Enthusiasts | Deepest circuit-to-CPU hardware construction loop | Desktop-only Steam game, steep learning curve, not browser/mobile/offline-first |
| **Khan Academy (Computing)** | 10–18 | Clear worked-example explanations, interactive JS/HTML canvas, mastery percentages | Requires constant internet/video bandwidth, limited tactile micro-game mechanics for younger Uzbek learners |
| **Brilliant.org** | 13+ | Crisp interactive visual proofs, "predict before see" active learning | Paywalled, not Uzbek-localized, minimal open sandbox & debugging practice |
| **Duolingo** | All ages | Habit loop, bite-sized 5-min sessions, friendly mascot coaching, SRS review | Gamification often rewards streaks/grinding over deep transfer; CS/math tracks mostly English |
| **CS Unplugged / Tynker** | 7–14 | Kinesthetic conceptual intuitions (binary cards, parity tricks, routing) without screen jargon | Paper activities lack instant feedback (<100ms) & automated test suites; Tynker is paywalled & English-first |

## Strategic Differentiation for «Oʻyna va oʻrgan»
1. **Uzbek-native first-class experience** (`ʻ` / `ʼ` verified typography + culturally grounded Silk Road workshop fantasy with Mirzo) + `ru` / `en`.
