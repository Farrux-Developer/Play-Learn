# GDD G04 — Bit va bayt koʻprigi (Binary, Hex, ASCII & Parity Lab)

- **Unit & Skills**: `U1` · `S014`, `S015`, `S016`, `S017`, `S018`, `S019`, `S021`, `S023`, `S025`, `S026`
- **Chunk Budget**: `<= 25 KB gz`

## 1. Core Loop & Intrinsic Integration
An 8-bit mechanical bridge of weighted flip-switches (`128, 64, 32, 16, 8, 4, 2, 1`) powers target cargo weights, Hex color lamps, 5x5 pixel stamps, or noisy parity packets:
- Toggle individual bits (`0`/`1`) to hit an exact decimal/hex target, draw a 1-bit pixel icon from a bitmask, or flip the **single corrupted bit** detected by even/odd parity across rows and columns (2D parity check).

## 2. Controls & Accessibility
- Bit switches `1..8` bound directly to keys `1`–`8` or `Space`/`Enter` focus toggles; live decimal/hex sum updates dynamically with `aria-live="polite"`.

## 3. Levels (15+: 5 Authored + Seeded Generator + Solver)
- **Levels 1–5 (Authored)**: (1) Powers of 2 weights (`0..15`); (2) Full 8-bit byte construction; (3) Nibble → Hex `#RRGGBB` preview; (4) ASCII bit pattern decoding (`'A' = 65`); (5) 2D 4×4 parity error repair (pinpoint the exact `(row, col)` flipped bit!).
- **Levels 6–15+ (Procedural Seeded)**: Seeded target numbers (`1..255`), nibble hex targets, or 2D parity grids with exactly 1 injected bit-flip (`seed` guarantees unique row+col parity intersection solver).

## 4. Feedback & Mastery
- Live positional breakdown (`64 + 8 + 2 = 74`) teaches binary place value instead of rote division.
