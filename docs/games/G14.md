# GDD G14 — Paket va qalqon (Networking, Crypto & Security Defense)

- **Unit & Skills**: `U10` · `S143`–`S145`, `S148`–`S151`, `S154`
- **Chunk Budget**: `<= 30 KB gz`

## 1. Core Loop & Intrinsic Integration
Learners run a mini web gateway defending an Uzbek service endpoint across three interlocking mechanics:
1. **Packet & DNS Tracer**: Resolve domain names via DNS, route packets around broken links (minimum latency), and diagnose HTTP `400/404/500` responses.
2. **Cipher & Hash Vault**: Decrypt/encrypt Caesar/XOR messages with a key, and distinguish reversible encryption from salted one-way hashing when storing passwords.
3. **Input Shield**: Spot and patch live XSS (`<script>`) or query-concatenation injection payloads using sanitization/parameterized templates.

## 2. Controls & Accessibility
- Keyboard-navigable packet hops, Caesar/XOR shift slider (`ArrowLeft/Right`), safe-query template selector/editor with instant live payload test runner.

## 3. Levels (15+: 5 Authored + Seeded Generator + Solver)
- **Levels 1–5 (Authored)**: (1) DNS + IP packet hop; (2) HTTP status triage; (3) Caesar/XOR key break via frequency clue; (4) Salt + hash password table repair; (5) Parameterize vulnerable search query against injection.
- **Levels 6–15+ (Procedural Seeded)**: Seeded cipher keys (`1..25` / 1-byte XOR) with verifiable Uzbek plaintext dictionary, seeded 6-node latency routing graphs, and parameterized sanitizer test suites with both benign and malicious edge payloads.

## 4. Feedback & Mastery
- Attack simulation shows *exactly* how an unsanitized input altered the HTML/query AST vs how escaping/parameterization neutralized it.
