# GDD G01 — Konveyer buyruqlari (Instruction Sequencing & Debugging)

- **Unit & Skills**: `U0` · `S001`, `S003`, `S005`, `S009`, `S011`, `S012`
- **Chunk Budget**: `<= 22 KB gz` (lazy-loaded module)

## 1. Core Loop & Intrinsic Integration
An automated parcel workshop robot stands on a grid conveyor with gates, sensors, and fragile cargo. The learner assembles or repairs a short command sequence (`OLGA`, `OʻNGGA_BURIL`, `CHAPGA_BURIL`, `OL`, `QOʻY`, `TEKSHIR`) and presses `Ishga tushir` (`Run`). The robot executes deterministically tick-by-tick; if a precondition fails (e.g., `OL` on empty slot or stepping on unpowered tile), execution freezes on the exact failing instruction and explains *why* that state broke.

## 2. Controls & Accessibility
- Mouse/touch drag-or-click to insert/reorder command tiles; `ArrowUp/ArrowDown` + `Alt+Up/Alt+Down` (or move buttons) for 100% keyboard reordering; `Space` to step, `Enter` to run.
- Screen reader live region announces robot coordinates, cargo state, and step reason after every tick.

## 3. Levels (15+: 5 Authored + Seeded Generator + Solver)
- **Levels 1–5 (Authored)**: (1) Tea/parcel straight sequence; (2) Obstacle avoidance; (3) Cargo pickup before door unlock; (4) Repair a 1-swap bug (`U0-L6`); (5) Edge-case empty conveyor guard.
- **Levels 6–15+ (Procedural Seeded)**: Generates solvable `4x4`–`6x6` conveyor grids from `seed` with 1 required pickup, 1 delivery target, and walls/one-way belts.
- **Built-in Solver**: BFS over `(x, y, dir, hasCargo)` guarantees shortest valid command sequence `<= parMoves` before accepting a generated level.

## 4. Feedback & Mastery
- Clean completion within step budget records a hint-free pass toward `S001`/`S012`; stepping back (`Orqaga`) lets learners inspect the failing state rather than restarting blindly.
