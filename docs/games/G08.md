# GDD G08 — Sikl konveyeri (Loop Bounds, Invariants & 2D Patterns)

- **Unit & Skills**: `U5` · `S071`–`S078`, `S080`–`S084`
- **Chunk Budget**: `<= 32 KB gz` (shares `Mirzo-kod` stepper)

## 1. Core Loop & Intrinsic Integration
A workshop tile stamp press executes learner-configured `uchun` (`for`) and `toki` (`while`) loops to produce an exact target sequence or 2D girih mosaic (`R × C` grid):
- **Mode A (Bounds & Step)**: Adjust `start`, `end`, `step`, or accumulator init (`0` vs `1`) to stop off-by-one and infinite-loop defects.
- **Mode B (Nested Loop Mosaic)**: Write/tune outer `r` and inner `c` loop rules so printed stamps match the target 2D matrix cell-for-cell.

## 2. Controls & Accessibility
- Number steppers (`ArrowUp/Down`) for loop parameters, live iteration-log table (`i`, `yigindi`, `holat`), `Qadam` (step 1 iteration) & `Ishga tushir` buttons, full screen-reader diff of expected vs actual grid.

## 3. Levels (15+: 5 Authored + Seeded Generator + Solver)
- **Levels 1–5 (Authored)**: (1) Off-by-one `1..4` vs `0..4`; (2) Fix infinite `toki (x > 0)` loop; (3) Sum/product accumulator initialization (`kop = 1`); (4) `toʻxta` / `keyingisi` filtering; (5) 2D diagonal / triangle mosaic pattern.
- **Levels 6–15+ (Procedural Seeded)**: Seeded arithmetic sequences, modulo-filter sequences, and `4×4`–`6×6` checkerboard/diagonal patterns verified by running the canonical `Mirzo-kod` solver within `<= 200` steps.

## 4. Feedback & Mastery
- Every iteration row highlights the invariant (`yigindi == 1 + ... + i`) and flags the exact iteration where actual output diverges from target.
