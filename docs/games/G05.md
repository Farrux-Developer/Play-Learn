# GDD G05 — Registr ustaxonasi (LMC Assembly Puzzle on Mirzo mashinasi)

- **Unit & Skills**: `U2` · `S028`, `S030`–`S041`
- **Chunk Budget**: `<= 32 KB gz` (shares core `Mirzo mashinasi` VM engine)

## 1. Core Loop & Intrinsic Integration
Learners write or repair concise assembly programs (`INP`, `OUT`, `LDA`, `STA`, `ADD`, `SUB`, `BRA`, `BRZ`, `BRP`, `HLT`, `DAT`) on a live 32/100-cell `Mirzo mashinasi` to transform multiple hidden `inQueue` tapes into target `outTray` sequences within an instruction/cycle budget.

## 2. Controls & Accessibility
- Code editor with line-number breakpoint toggles, `Orqaga`/`Oldinga` stepper buttons, memory-cell inspector table (`role="grid"`), keyboard shortcuts (`F8` step, `F9` run/pause).

## 3. Levels (15+: 5 Authored + Seeded Generator + Solver)
- **Levels 1–5 (Authored)**: (1) Echo + constant (`INP`, `ADD ONE`, `OUT`, `HLT`); (2) Two-number sum & difference; (3) Fix missing `HLT` / wrong `STA` address bug; (4) Max of two inputs using `SUB` + `BRP`; (5) Countdown loop `N..1` using `BRZ`/`BRA`.
- **Levels 6–15+ (Procedural Seeded)**: Parameterized linear transforms (`a*x + b`), pairwise max/abs-diff, and bounded loop sum generators verified across `>= 4` test input tapes by the `Mirzo mashinasi` VM runner + canonical reference solution.

## 4. Feedback & Mastery
- Highlights Fetch (`PC -> IR`) vs Execute (`ACC <-> mem[addr]`) so learners see why `ADD 10` adds *cell 10's content*, not literal `10`.
