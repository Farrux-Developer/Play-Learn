# GDD G03 — Xotira qutilari va iz (Variable Trace, Swap & Bug-Fix Puzzle)

- **Unit & Skills**: `U4` · `S058`, `S059`, `S060`, `S061`, `S063`, `S065`, `S066`, `S070`
- **Priority**: **Phase 4 Vertical Slice**
- **Chunk Budget**: `<= 30 KB gz` (lazy-loaded module backed by `Mirzo-kod` stepper)

## 1. Core Loop & Intrinsic Integration
Learners operate a live memory shelf of labeled variable boxes (`x`, `y`, `temp`, `qoldiq`, `matn`) alongside a 4–8 line `Mirzo-kod` trace:
- **Predict-Trace Mode**: Before each line executes, the learner enters or picks the box's new value (or selects which variable gets overwritten) and verifies against the live `Mirzo-kod` AST stepper.
- **Swap & Arithmetic Repair Mode**: A broken snippet loses a value (e.g., `a = b; b = a` overwrites `a`!), mixes `"5" + 5`, or computes wrong `%` / `//`. Learner edits/reorders statements or fills the missing expression and runs hidden test inputs.

## 2. Controls & Accessibility
- Keyboard-accessible numeric/text box inputs (`Enter` to commit step, `ArrowLeft/ArrowRight` for step back/forward), clear contrast badges on changed variables (`changedVars` glow).
- Screen reader announces: `"2-qator bajarildi: 'a' qutisidagi 10 oʻrniga 15 yozildi."`

## 3. Levels (15+: 5 Authored + Seeded Generator + Solver)
- **Levels 1–5 (Authored)**: (1) Sequential overwrite (`ball = 10 -> ball = 15`); (2) Self-update (`hisob = hisob + 3`); (3) Broken swap without `temp` (`a <-> b`); (4) Integer vs modulo split (`daqiqa // 60`, `daqiqa % 60`); (5) String + number type bug in receipt formatter.
- **Levels 6–15+ (Procedural Seeded)**: Generates randomized 3–5 line variable update chains (with seeded initial values `a, b, c` and arithmetic `+ - * % //`) or missing-assignment puzzles. Built-in `Mirzo-kod` interpreter evaluates exact ground-truth trace frames and validates uniqueness of final box states.

## 4. Feedback & Mastery
- When a learner writes the stale value after an overwrite (`a = b; b = a`), an animation visibly drops the erased number out of box `a` and highlights why `temp` is needed.
