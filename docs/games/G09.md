# GDD G09 — Funksiya fabrikasi (Black-Box Composition & Call Stack)

- **Unit & Skills**: `U6` · `S085`–`S090`, `S092`, `S093`, `S096`, `S097`
- **Chunk Budget**: `<= 28 KB gz`

## 1. Core Loop & Intrinsic Integration
Learners connect modular function machines (`f(x)`, `g(x)`, `h(x, y)`) in a pipeline and inspect the live **Call Stack (`Chaqiruvlar steki`)** frame-by-frame:
- **Pipeline Synthesis**: Compose helper functions `f(g(x))` to match hidden test-case outputs.
- **Scope & Return Rescue**: Spot why a function returned `undefined` (used `chopEt` instead of `qaytar`), exited too early inside a loop, or accidentally mutated a global instead of a local parameter.

## 2. Controls & Accessibility
- Keyboard-navigable function slots (`Enter` to insert/swap helper, `ArrowUp/ArrowDown` to trace stack frames), code editor fallback for `Qurish` mode.

## 3. Levels (15+: 5 Authored + Seeded Generator + Solver)
- **Levels 1–5 (Authored)**: (1) `qaytar` vs `chopEt` fix; (2) Compose `double(inc(x))` vs `inc(double(x))`; (3) Early `qaytar` inside loop bug; (4) Local vs global shadowing trace; (5) Two-helper pipeline (`tozalash` → `hisobla`).
- **Levels 6–15+ (Procedural Seeded)**: Seeded compositions of `2–3` pure numeric/string transforms verified by algebraic/enumeration solver guaranteeing at least one valid pipeline matches all test cases.

## 4. Feedback & Mastery
- Stack frame cards visibly stack upward with separate `lokal` badges so learners grasp why two `x` variables don't collide.
