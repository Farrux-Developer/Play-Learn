# GDD G12 — Qidiruv va saralash dueli (Binary Search & Big-O Budget)

- **Unit & Skills**: `U8` · `S114`–`S125`, `S127`, `S128`
- **Chunk Budget**: `<= 30 KB gz`

## 1. Core Loop & Intrinsic Integration
Learners compete under a **strict step/comparison budget**:
- **Binary Search Oracle (`Ikkilik qidiruv`)**: Find a hidden target (or lower-bound insertion slot) in an array of `N = 16..1024` tiles in `<= ceil(log2(N))` probes by inspecting `mid`, and repair buggy `lo = mid` infinite-loop binary search code.
- **Sorting Workbench (`Saralash`)**: Execute swap/insert primitives or choose the right algorithm (`Insertion` on nearly sorted vs `Merge` on `N = 10 000`) within an operation-count meter (`O(N²)` blows the budget!).

## 2. Controls & Accessibility
- Click/Enter array cell to probe `mid`, swap two adjacent elements with `Space` + `ArrowLeft/Right`, toggle view between visual bars and `lo/mid/hi` pointers.

## 3. Levels (15+: 5 Authored + Seeded Generator + Solver)
- **Levels 1–5 (Authored)**: (1) Sorted vs unsorted binary search trap; (2) Find value in 15 tiles in `<= 4` probes; (3) Fix `lo = mid` infinite loop bug; (4) Bubble vs Insertion swap-count comparison; (5) `Merge` two sorted halves into one in `O(N)`.
- **Levels 6–15+ (Procedural Seeded)**: Seeded sorted arrays (`N = 15..127`) with guaranteed `<= ceil(log2(N))` binary search oracle and randomized nearly-sorted/reverse arrays for comparison-budget challenges.

## 4. Feedback & Mastery
- Live Big-O step meter shows how `N = 1000` takes `<= 10` probes via binary search vs `1000` linear checks.
