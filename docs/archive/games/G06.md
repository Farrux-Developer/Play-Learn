# GDD G06 — Tarmoq yoʻnalishi (Decision Tree & Branch Coverage)

- **Unit & Skills**: `U3` · `S044`, `S050`, `S051`, `S052`, `S054`
- **Chunk Budget**: `<= 24 KB gz`

## 1. Core Loop & Intrinsic Integration
An automated ticket/tariff gate routes incoming traveler payloads (`{ yosh, talaba, bagaj }`) through chained `agar / aks holda agar` rules. Learners either:
1. Reorder overlapping branch thresholds so every passenger lands in the right bin (fixing unreachable-branch shadow bugs like checking `ball >= 50` before `ball >= 90`!), OR
2. Craft a **minimal test suite** of inputs hitting every single branch (`100% branch coverage`).

## 2. Controls & Accessibility
- Reorderable branch cards (`Alt+Up/Down` or arrows), inline boundary stepper (`<` vs `<=`), test-input sliders/number fields, keyboard full support.

## 3. Levels (15+: 5 Authored + Seeded Generator + Solver)
- **Levels 1–5 (Authored)**: (1) `>` vs `>=` boundary off-by-one; (2) Shadowed grade bracket (`>= 60` before `>= 90`); (3) Short-circuit guard (`n != 0 && 100 / n > 5`); (4) Mutually exclusive `agar` vs `aks holda agar` double-discount bug; (5) Minimal input set covering 4 branches.
- **Levels 6–15+ (Procedural Seeded)**: Generates multi-bracket threshold trees (`2..4` cutpoints) with scrambled order or boundary-equality mutations; deterministic interval solver verifies unique partition coverage across all intervals.

## 4. Feedback & Mastery
- Visually dims "dead/unreachable" branches in coral and displays the exact counterexample input (e.g., `ball = 92` fell into `>= 60`!).
