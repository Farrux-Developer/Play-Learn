# GDD G10 — Vagon saralash: Stek va Navbat (Stack, Queue & Ring Buffer)

- **Unit & Skills**: `U7` · `S104`–`S107`, `S113`
- **Chunk Budget**: `<= 26 KB gz`

## 1. Core Loop & Intrinsic Integration
Numbered freight wagons arrive on an input track and must depart in an exact target order—or balance bracket tokens `()[]{}`—using a **Stek (LIFO siding)**, **Navbat (FIFO lane)**, or **Halqa bufer (fixed-cap ring buffer)**:
- **Routing Mode**: Choose `push`/`pop` or `enqueue`/`dequeue` operations to reorder wagons within capacity limits (`maxStackSize`). Some target permutations are mathematically impossible with 1 stack — learners learn to recognize *why*!
- **Ring Buffer Mode**: Track `head`, `tail`, and `(tail + 1) % N` wrap-around without overwriting unread cargo.

## 2. Controls & Accessibility
- Buttons + keyboard hotkeys (`1` push/enqueue, `2` pop/dequeue, `Z` undo step), live ARIA announcements of stack top & queue front.

## 3. Levels (15+: 5 Authored + Seeded Generator + Solver)
- **Levels 1–5 (Authored)**: (1) LIFO reversal; (2) FIFO vs LIFO choice; (3) Balanced brackets `([{}])` stack trace; (4) Shunting target `[2, 1, 3]`; (5) Ring buffer capacity-4 wrap-around.
- **Levels 6–15+ (Procedural Seeded)**: Generates valid stack-sortable permutations (by simulating random legal `push`/`pop` moves from `1..N`!) or valid bracket strings with injected mismatch bugs; solver guarantees 100% reachability.

## 4. Feedback & Mastery
- Shows both `LIFO` top pointer and `FIFO` `head/tail` pointers (`% N`) live on every move.
