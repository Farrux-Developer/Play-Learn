# GDD G02 — Mantiq darvozalari (Boolean Gates & Truth-Table Routing)

- **Unit & Skills**: `U3`, `U4` · `S042`, `S043`, `S045`, `S046`, `S047`, `S048`, `S049`, `S055`
- **Priority**: **Phase 4 Vertical Slice**
- **Chunk Budget**: `<= 28 KB gz` (lazy-loaded module, pure SVG/HTML + MotionCore cues)

## 1. Core Loop & Intrinsic Integration
A blueprint circuit board connects input switches (`A`, `B`, `C`, or comparison probes like `yosh >= 18`, `ball > 60`) through `AND` (`VA`), `OR` (`YOKI`), `NOT` (`EMAS`), and `XOR` gates to an output lock (`OCHIQ` / `YOPIQ`).
- **Mode A (Signal Routing)**: Flip input toggles or place missing gates in empty sockets so the live output matches **every row** of the required truth table simultaneously (one wrong row highlights in coral!).
- **Mode B (Fault Isolation)**: Find the single miswired gate causing an unexpected `1` or `0` on a failing test row.

## 2. Controls & Accessibility
- Click/tap socket to cycle or choose gate (`AND`, `OR`, `NOT`, `XOR`), toggle inputs (`0`/`1`) with `Space`/`Enter`, `Tab` moves across sockets and truth-table rows.
- Every gate node displays both symbol and Uzbek label (`VA`, `YOKI`, `EMAS`, `XOR`) — never color-only!

## 3. Levels (15+: 5 Authored + Seeded Generator + Solver)
- **Levels 1–5 (Authored)**: (1) Single `VA` lock (`A && B`); (2) `YOKI` + `EMAS` safety valve; (3) Operator precedence trap (`A || B && C` vs `(A || B) && C`); (4) De Morgan equivalence (`!(A && B)` vs `!A || !B`); (5) 3-input threshold + comparison gate (`yosh >= 18 && bilet == rost`).
- **Levels 6–15+ (Procedural Seeded)**: Generates 2–3 input 2-layer boolean DAGs with 1–2 missing gate slots or 1 faulty gate, verified against exhaustive `2^n` truth table evaluation so a valid assignment always exists (and uniqueness/minimal ambiguity is checked by brute-force gate solver).

## 4. Feedback & Mastery
- Live wire voltage (`0` dim chalk / `1` glowing glaze) animates signal propagation left-to-right so learners *see* De Morgan and precedence rather than guessing.
