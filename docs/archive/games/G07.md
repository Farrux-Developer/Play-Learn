# GDD G07 — Kod yigʻuvchi: Parsons ustaxonasi (Reordering + Distractors)

- **Unit & Skills**: `U4` · `S062`, `S064`, `S065`, `S068`, `S069`
- **Chunk Budget**: `<= 28 KB gz` (backed by `Mirzo-kod` evaluator)

## 1. Core Loop & Intrinsic Integration
Learners drag/move shuffled `Mirzo-kod` blocks (including 1–2 plausible **distractor** blocks with subtle bugs like `=` vs `==` or wrong indentation/scope) from a tray into the solution workbench, set block indentation depth (`Tab`/`Shift+Tab` or `←`/`→` indent buttons), and run automated `Mirzo-kod` unit tests.

## 2. Controls & Accessibility
- 100% keyboard operable Parsons UX: `Space`/`Enter` selects/moves block between tray and solution, `ArrowUp/ArrowDown` reorders, `ArrowLeft/ArrowRight` changes block nesting depth.

## 3. Levels (15+: 5 Authored + Seeded Generator + Solver)
- **Levels 1–5 (Authored)**: (1) Input + greeting; (2) Safe variable swap with distractor (`a = b` trap); (3) Discount calculation with parentheses distractor; (4) Age validation `if/else` with indentation; (5) Temperature converter + formatted string output.
- **Levels 6–15+ (Procedural Seeded)**: Parameterized Parsons templates (variable names, operators, constants, distractor pairs) shuffled deterministically by `seed`; test runner executes the assembled AST against `>= 3` hidden test inputs.

## 4. Feedback & Mastery
- Unused distractor explanations reveal *why* the decoy block was a trap when tested.
