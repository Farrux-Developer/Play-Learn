# Agent Session Memory & Rules

Before making any code or documentation changes in this repository:
1. Read `docs/PROJECT_BRIEF.md` (Master Brief v1 — mission, principles, game loop, curriculum, architecture, budgets, phase gates, and anti-goals).
2. Read `docs/PROGRESS.md` for current phase status, measured baselines, open questions, and recent ADRs.
3. Follow the strict phase-by-phase workflow (`Phase 0` → `Phase 6`): complete one phase, verify with real commands/metrics, update `docs/PROGRESS.md`, report in the Section 15 format, and STOP until the user replies `"go"`.
4. Never write feature code without checking ADR decisions in `docs/adr/`. Never state unmeasured metrics or ship placeholder/machine-translated production content as reviewed.
